# community

Claude Code mods and plugins by Leo Ho.

## Install

```
/plugin marketplace add le0u0/community
/plugin install <name>@community
```

## Mods

| Name | What it does |
| --- | --- |
| `campfire` | Hides tool calls and shows an animated campfire above the prompt that grows as the job nears done |
| `watch-out` | Shows context window use and plan usage |

## Plugins

| Name | What it does |
| --- | --- |
| `just-do-it` | Project-agnostic manager, agents, and skills for ticket-driven development: think, plan, develop, test, review |
| `ping-me` | macOS alerts for Claude Code questions, approvals, and responses from any terminal, with click-to-open Cursor or VS Code |
